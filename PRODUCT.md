# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React (TypeScript) + Vite, shadcn/ui on Tailwind CSS for the frontend; Python + FastAPI for the backend, tested with pytest. Full rules live in CLAUDE.md.

## Users

A single user, the owner: a personal to-do tool for organizing their own tasks and day.

## Product Purpose

A personal to-do app where AI helps plan: it breaks tasks down, prioritizes, and schedules them. The user still does the work. Success means the user knows what to do next without hand-sorting their list.

## Positioning

AI planning and sorting on top of a to-do list, built for one person. The AI does not carry out tasks itself.

## Capabilities and Constraints

- AI task breakdown, prioritization, and scheduling.
- Backend is secure-first: every endpoint requires an API key unless explicitly made public.
- Functional programming throughout frontend and backend.
- Open: which AI model/provider, how scheduling ties to a calendar, data storage.

## Brand Commitments

- Everything must look premium: refined, polished, intentional.

## Evidence on Hand

None yet. No testimonials, data, or assets exist; do not fabricate any.

## Product Principles

1. The next action should always be obvious.
2. The AI suggests; the user decides.
3. Single-user focus: no team or sharing overhead.
4. Private and secure by default.
